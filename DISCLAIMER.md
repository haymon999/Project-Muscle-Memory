# Disclaimer

Muscle Memory Patcher is not malware, not a mod menu, and not a cheat
tool. There is nothing here that touches, attacks, or talks to the
official Critical Ops servers. The game in this setup only ever talks to
a small server running on your own PC, and only with the one old version
listed in the README (`1.32.0.f1831`).

What this is: a way to keep playing that specific old release offline —
bot matches and menus on your own machine, with a locally stored profile.
What this is not: hacks for online play, account tools, unlocking
services, or anything that affects other players. None of that works
here, and none of it is the point.

You need your own copy of the old APK (for example the archived
`1.32.0.f1831` package). Don't re-upload the game itself anywhere.
